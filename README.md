A Fediverse robot account that posts the latest public records requests filed and completed at muckrock.com at [mastodon.palewi.re/@muckrockbot](https://mastodon.palewi.re/@muckrockbot)

The downloader uses MuckRock API v2 and requires `MUCKROCK_USERNAME` and
`MUCKROCK_PASSWORD` environment variables. Configure matching repository secrets
for the scheduled GitHub Actions workflow.
